Module Stateful.Concurrent_rule

One possible action in a concurrent stateful test.

type 'state t

create ?group ~name ~step () declares a concurrent rule.

  • group defines the concurrency group of the rule. Only rules within the same group may run concurrently. Rules without an explicit group are in one anonymous group.
  • name is printed in the final output when the rule is run.
  • step tc state performs one application of the rule, drawing any arguments it needs from tc and updating state in place. tc is valid only for that step.
val create : ?group:string -> name:string -> step:(test_case -> 'state -> unit) -> unit -> 'state t
val name : _ t -> string

Returns the name of the rule.

val group : _ t -> string

Returns the concurrency group of the rule.
