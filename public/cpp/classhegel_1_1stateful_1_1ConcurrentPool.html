Detailed Description

template<typename T>
class hegel::stateful::ConcurrentPool< T >

A pool of values that concurrent workers can share.

Store the pool in a concurrent state machine. Use add to add a value from a worker, values_reusable to draw a copy without removal, and values_consumed to draw and remove a value.

libhegel selects a value and updates the pool as an atomic operation. A draw rejects the test case if the pool is empty.

A ConcurrentPool is not copyable.
