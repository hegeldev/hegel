Detailed Description

template<typename M>
class hegel::stateful::ConcurrentRule< M >

An action that a worker can apply to a concurrent state machine.

Rules in the same group can run concurrently. Rules in different groups cannot. A rule that does not specify a group uses anonymous_group.

Template Parameters
MThe state-machine type that the rule acts on
