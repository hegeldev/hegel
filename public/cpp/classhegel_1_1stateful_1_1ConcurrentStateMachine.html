Detailed Description

template<typename Derived>
class hegel::stateful::ConcurrentStateMachine< Derived >

Base class for a concurrent state machine.

Derive a machine from this class. Define a rules() member that returns the rules for the machine. Override invariants to add invariant checks.

The example below defines three groups. The alpha and beta rules can run concurrently because both use the letters group. The one rule uses the numbers group and does not overlap with them. The anonymous rule uses anonymous_group and does not overlap with either named group.

struct MyConcurrent
: hegel::stateful::ConcurrentStateMachine<GroupedMachine> {
std::mutex mutex;
std::vector<std::string> log;
std::vector<hegel::stateful::ConcurrentRule<GroupedMachine>>
rules() {
return {
{"alpha", "letters",
[](hegel::TestCase&, GroupedMachine& m) {
std::lock_guard<std::mutex> lock(m.mutex);
m.log.push_back("alpha");
}},
{"beta", "letters",
[](hegel::TestCase&, GroupedMachine& m) {
std::lock_guard<std::mutex> lock(m.mutex);
m.log.push_back("beta");
}},
{"one", "numbers",
[](hegel::TestCase&, GroupedMachine& m) {
std::lock_guard<std::mutex> lock(m.mutex);
m.log.push_back("one");
}},
{"anonymous", [](hegel::TestCase&, GroupedMachine& m) {
std::lock_guard<std::mutex> lock(m.mutex);
m.log.push_back("anonymous");
}},
};
}
};
HEGEL_TEST(grouped_machine)(hegel::TestCase& tc) {
GroupedMachine machine;
hegel::stateful::run_concurrent(machine, tc, 1, 3);
}
