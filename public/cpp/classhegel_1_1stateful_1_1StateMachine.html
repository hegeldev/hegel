Detailed Description

template<typename Derived>
class hegel::stateful::StateMachine< Derived >

Base class for a state machine. Consists of the state, the rules, and the invariants that act on it.

Derive from it with the deriving type as Derived and define

std::vector<Rule<Derived>> rules();

returning the actions the test may apply. Optionally override invariants to add predicates checked before the first step and after every valid step. The deriving object holds the state. Its rules mutate it in place. Pass an instance to run.
