579// Stringification takes two steps because `#` reads its argument before any
580// macro in it expands. `HEGEL_INTERNAL_STRINGIFY_(__LINE__)` alone therefore
581// gives "__LINE__". Passing the argument through a macro that does not apply
582// `#` expands it first, so the second macro stringifies the line number.
583#define HEGEL_INTERNAL_STRINGIFY_(x) #x
584#define HEGEL_INTERNAL_STRINGIFY(x) HEGEL_INTERNAL_STRINGIFY_(x)

586// The call site, which the engine uses to tell one requirement from another.
587// The three parts join into one string literal at compile time.
588//
589// `#` applies only to a parameter of a macro that takes parameters, so this
590// macro cannot stringify __LINE__ itself. A bare `#__LINE__` here leaves the
591// `#` in the token stream and fails to compile.
