RELEASE_TYPE: minor

This release adds grammar-based string generation. `hegel_grammar_new` compiles a grammar written in the syntax of the [Lark](https://lark-parser.readthedocs.io/en/stable/grammar.html) parsing library into a `hegel_grammar_t` handle (freed with `hegel_grammar_free`), taking the start rule, size and depth caps, an alphabet string generator for the regex terminals, explicit string generators for named terminals, and an import callback through which the binding supplies `%import`ed grammar files (Lark's bundled `common`, `python`, `unicode` and `lark` grammars are built in). `hegel_generate_grammar` then draws a string of the grammar into a `hegel_generate_string_result_t`, as `hegel_generate_string` does. The engine supports the whole grammar language and generates strings Lark's Earley parser accepts, inserting `%ignore`d terminals where a lexer would skip them and avoiding strings Lark's basic lexer would read differently where the grammar allows; the design is described in the module documentation of `src/native/lark/generate.rs`.
