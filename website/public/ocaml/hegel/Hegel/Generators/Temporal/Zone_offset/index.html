Module Temporal.Zone_offset

The offset a zone has in force at an instant; see offset_at.

type t = {
  1. offset : Offset.t;
  2. is_dst : bool;
  3. abbreviation : string;
}

is_dst is the database's daylight-saving flag, informational only, and abbreviation the abbreviation in force, such as EST, or -00 when the offset is unknown.
