Module Stateful.Invariant

A property that must always be true in a stateful test.

type 'state t
val create : name:string -> inv:(test_case -> 'state -> unit) -> ?always_check:bool -> ?pause_faults:bool -> unit -> 'state t

Declares an invariant.

  • name is printed in the final output if the test fails on an invariant
  • inv tc state checks the invariant on state. Anything it draws or notes through tc prints indented under the line before it.
  • always_check defaults to false. When true, the invariant is checked after every step. Otherwise, it is sampled.
  • pause_faults defaults to false. When true, every run of the invariant is bracketed with Internal.pause_faults and Internal.unpause_faults on the test case (the unpause runs even when the invariant raises), so that inside Antithesis fault injection is paused for the duration of the check; elsewhere the flag has no effect.

Every invariant is checked on the initial and final states.

With the PPX, an invariant takes the following options, in any order and each optional: [@@invariant { always_check = true | false; pause_faults = true | false }].

let short =
  Stateful.Invariant.create
    ~name:"short"
    ~inv:(fun _tc stack -> assert (List.length !stack < 10))
    ()
;;
val name : _ t -> string

Returns the name of the invariant.

val always_check : _ t -> bool

Returns whether the invariant is checked after every step.

val pause_faults : _ t -> bool

Returns whether fault injection is paused while the invariant runs.
