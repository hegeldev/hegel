Module Settings.Nondeterminism_strictness

How a run handles nondeterministic test behavior. In hegel.toml: quiet, warn, or error.

type t =
  1. | Quiet
    (*

    Switch to nondeterministic handling silently.

    *)
  2. | Warn
    (*

    Quiet, but print a notice per run.

    *)
  3. | Error
    (*

    Abort the run with a flaky-test error.

    *)
